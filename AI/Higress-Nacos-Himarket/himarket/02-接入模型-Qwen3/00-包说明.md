# 00 · 跨集群接入 Qwen3-32B（实操包）

> `0N-` 文档｜`1N-` 可执行脚本｜`2N-` YAML 清单｜`00-` 本说明。

## 这个包做什么

把模型集群的 Qwen3-32B 接入 HiMarket 集群，在 HiChat 里可用；已验收。

## 一对一配对表

| 角色 | 文件 | 用途 |
|---|---|---|
| 主手册 | `01-全流程配置手册.md` | 六阶段主手册：三个「名字」辨析、取值清单、七级验收、16 条故障速查、10.2 输出截断三层判定、变更回滚 |
| 清单（生产） | `21-qwen3-32b-modelserving.yaml` | Kthena ModelServing，昇腾 910×8、TP=8、共置单角色，**正式路径** |
| 清单（排障） | `22-vllm-qwen3-32b-deploy.yaml` | 裸 Deployment，**只在排障时用**，用来隔离「是不是 Kthena 的问题」 |
| 脚本 | `11-test-qwen3.sh` | 四步验证：模型名 → 普通对话 → tool calling → 多轮回传 |

## 执行顺序

```
01-全流程配置手册.md（读第 1–3 章取值）→ 改 21-*.yaml 的模型路径/服务名后 apply
→ 11-test-qwen3.sh（四步全过）→ 手册第 4–6 章在 HiMarket 建 API 产品
```

## 验收 / 三个易错点

`11-test-qwen3.sh` 四步全通 + HiChat 能正常对话。
① 域名用**点号** `qwen3.32b.example.internal`，模型名用**横线** `qwen3-32b`，混用直接 404；
② `himarket-server` 需要 hostAliases 指向网关 ClusterIP；
③ `openaiCustomUrl` 要填到 `/v1/chat/completions` 完整端点。
