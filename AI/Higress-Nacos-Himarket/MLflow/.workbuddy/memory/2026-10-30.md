## GitLab + Jenkins 离线 Helm 部署准备
- 环境：移动云 KCS、气隙/堡垒机、Higress 网关、私有 Harbor。
- 版本锁定：GitLab Helm chart 9.11.16 (GitLab 18.11.14)；Jenkins chart 5.10.5 (Jenkins 2.580.2, jdk25)。
- 关键选型：GitLab 19.0/chart 10.0 起移除内置 PostgreSQL/Redis/MinIO，必须外接；因此离线实验选 9.11.16 全内置方案，10.5.4 + 外部依赖列为阶段二。
- 镜像映射策略：只替换 registry 主机名、保留仓库路径，Harbor 预建 gitlab-org/bitnami/minio/jenkins/kiwigrid 等项目。
- 离线 Jenkins 插件的唯一可行做法：jenkins-plugin-manager 解析依赖 -> 预烤进自建镜像 -> chart 里 installPlugins 置空。
- 产出：docs/GitLab-Jenkins-离线部署准备清单.md、scripts/10-prepare-bundle.sh、scripts/20-load-and-install.sh、values/*.yaml、jenkins/Dockerfile.plugins。

## 待确认风险
- KCS 托管节点能否信任内部 CA（决定 Harbor 证书方案）
- 节点架构是否 ARM64（CNG 镜像 arm64 覆盖不全）
- 集群资源是否够 GitLab 全量（约 4~6C/9~12Gi requests）

## 版本兼容性核对（已确认）
- GitLab 与 Jenkins 无版本耦合，仅通过 git/PAT、webhook、Registry API v2 交互。
- Jenkins 2.580 只支持 Java 21/25（Java 17 自 2.555.1 起不支持）；Java 25 自 LTS 2.541.1 起支持，故 chart 默认 jdk25 镜像正确。
- 2.580 起 Jenkins 不再随 WAR 捆绑 junit / mailer / matrix-auth / matrix-project，离线插件清单必须显式列出。
- Blue Ocean 自 2026-07 废弃，已从离线清单移除，改用 pipeline-stage-view。
- GitLab chart 9.11.16 的 Chart.yaml 未声明 kubeVersion 硬约束，依赖 networking.k8s.io/v1。

## MLOps 两层落地手册（离线 kthena 场景）
- 背景：用户已在集群用 kthena(Volcano 子项目，LLM serving 编排层) 跑起 DeepSeek-32B，问是否再叠 MLOps 栈。结论：KServe 与 kthena 重叠不上；Kubeflow 离线成本远超收益（只能 QLoRA，Training Operator/Katib 用不上，且与 volcano gang 调度冲突）；Evidently 的表格 ML 漂移检测对 LLM 不适用，换成 golden set 回归评测 + 推理指标。
- 已核对 kthena CRD 字段：AutoscalingPolicy 指标 `vllm:num_requests_waiting` / `vllm:kv_cache_usage_perc`，targetValue + tolerancePercent + stable/panic 双模式；AutoscalingPolicyBinding 用 homogeneousTargets(+subTargets 支持 Role 级)；ModelRoute 用 `targetModels[].weight`(0-100) 做 canary；ModelBooster 的 `loraAdapters[].artifactURL` 支持 s3:// 且 runtime 可动态 load/unload（需 VLLM_ALLOW_RUNTIME_LORA_UPDATING=True），router 有 lora-affinity 插件。
- 关键架构判断：模型制品存储走 `pvc://` 或 `s3://`（两者都是一行 YAML），省掉 initContainer/打镜像；GitOps 同时管应用与 kthena 清单，Git 仍是唯一事实源。
- 环境事实（2026-10-30 用户告知）：**集群已有 NFS 共享存储**，因此制品存储采用 `pvc://`（RWX 天然跨节点，规避 hostpath 跨节点失效），MinIO 降级为可选方案。NFS 三条约束：默认 mount 参数下 65GB 权重加载可能 10min+（需 nfsvers=4.1 + rsize/wsize=1048576）；`hard` 挂载断连会让 Pod 静默挂起；Argo artifactRepository 不支持 PVC，需用 volumeMounts 共享卷 + `archive: none` 变通。
- 产出：docs/MLOps-两层落地实施手册.md（第一层 4 个实验：量化对比/PD 分离/队列深度扩缩/LoRA 多租户；第二层闭环：QLoRA→四层评测门禁→MLflow 注册→ModelRoute 灰度→秒级回滚）。
